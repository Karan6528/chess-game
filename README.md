♟️ Chess Game

A browser-based chess game developed during a one-day hackathon at GISMA University of Applied Sciences.

The project was created using HTML, CSS, and JavaScript, with the goal of building a functional and interactive chess experience within a limited development time.

🚀 Features

♟️ Interactive chess board

👥 Two-player gameplay

🔄 Turn-based game system

♜ Chess piece movement

🎨 Clean and responsive interface

⚡ Built with vanilla HTML, CSS, and JavaScript

⏱️ Developed during a one-day hackathon

🛠️ Technologies Used

HTML5 – Structure of the application

CSS3 – Styling and responsive design

JavaScript – Game logic and interactions

📂 Project Structure
chess-game/
│
├── index.html      # Main HTML file
├── style.css       # Styling and layout
├── script.js       # Chess game logic
└── README.md       # Project documentation

🎮 How to Run

Clone the repository:

git clone https://github.com/YOUR-USERNAME/chess-game.git


Open the project folder.

Open index.html in your web browser.

No additional installation or dependencies are required.
